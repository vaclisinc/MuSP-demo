# MuSP Demo Guide

This repository is the research demo for MuSP-Bench, published as a static GitHub Pages site. Preserve the benchmark's released question wording, modality labels, and answer-contract semantics. Editorial groupings in the question explorer must remain explicitly distinguished from canonical annotations.

Source research and benchmark-generation code live in the sibling `../muno-lm` repository. The canonical released QA file is `https://huggingface.co/datasets/milan477/MuSP-Bench/blob/main/data/questions.csv`.
