# MuSP Demo Guide

This repository is the public-facing interactive demo for MuSP-Bench. Preserve the benchmark's released question wording, modality labels, and answer-contract semantics. Editorial groupings such as the five explanatory layers must remain explicitly distinguished from canonical annotations.

Source research and benchmark-generation code live in the sibling `../muno-lm` repository. The canonical released QA file is `https://huggingface.co/datasets/milan477/MuSP-Bench/blob/main/data/questions.csv`.
